# Thực hành CSS nội tuyến trong HTML

Bài tập sử dụng thuộc tính `style` để định dạng trực tiếp các phần tử HTML:

- Tiêu đề màu xanh dương.
- Đoạn văn màu đỏ và in đậm.
- Đoạn văn in nghiêng và căn giữa.
- Đoạn văn có kích thước 20px và gạch chân.

Mở file `index.html` bằng trình duyệt để xem kết quả.
